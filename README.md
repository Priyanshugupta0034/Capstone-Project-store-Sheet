# Store Sheet - Capstone Project

## Overview
Store Sheet is a capstone project that helps small retail stores manage their
daily operations in one organized spreadsheet. It tracks products, stock levels,
sales, and purchases, and automatically calculates totals, profit, and
low-stock alerts, replacing manual record keeping with a faster, more accurate
system.

## Problem Statement
Many small stores still record sales and inventory in notebooks, which leads to
calculation errors, missing records, and poor stock visibility. This project
provides a simple, structured, and reusable solution.

## Objectives
- Maintain a complete product and inventory record
- Track daily sales and purchases
- Automatically calculate revenue, cost, and profit
- Highlight low-stock items
- Generate summary reports for quick decision-making

## Features
- Product master list (ID, name, category, price, quantity)
- Daily sales entry with automatic total calculation
- Real-time stock updates
- Low-stock alerts using conditional formatting
- Monthly sales and profit summary
- Charts and dashboard for visual insights

## Tech Stack
- Microsoft Excel / Google Sheets
- Formulas: SUMIF, VLOOKUP/XLOOKUP, IF, COUNTIF
- Pivot tables and charts
- (Optional) Google Apps Script / VBA / Python for automation
